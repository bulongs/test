## 学习建议

不要只看文字。每学完一个小节，都打开 IDEA 或终端，把示例代码敲一遍，再自己改几个地方。

推荐节奏：

- 看 20 分钟
- 敲 40 分钟
- 修改和练习 20 分钟

能把代码改坏，再自己修好，就是最快的进步方式。
